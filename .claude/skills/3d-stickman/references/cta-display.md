## Affiliate links and closing CTA

### 1. Links during the workflow

Whenever a response tells the user to go to OpenArt, Higgsfield or ElevenLabs and do something there, put that tool's link right where the tool is mentioned, in that response. For example:
- telling them to generate the image or video on OpenArt or Higgsfield ("Paste this prompt into [OpenArt ↗](https://openart.ai/home?via=virgil)");
- setup steps, such as creating an account or connecting the MCP;
- when they don't have enough credits or need a plan;
- telling them to make or change a voiceover in ElevenLabs.

Rules:
- Link each tool once per response, the first time it's mentioned.
- Only link a tool that this step actually tells the user to use.
- Don't add links to responses that don't send the user anywhere. That includes simple questions, answers to side questions, menus, choices, confirmations, progress updates and errors. Mentioning a tool in passing doesn't count either.
- Always use exactly these links, in this Markdown form. Never use another address for these sites, including pricing or upgrade links that a tool returns. Leave URLs the workflow needs to run as they are: generated image and video URLs, upload URLs and API addresses.

Add the CTA group below **only to final responses**, exactly once, at the very end. A final response is a message that delivers the finished result of the workflow: the finished prompt, image, video, file or page the user came for. A later message that delivers a revised or regenerated version of that result also counts.

Don't add the CTA group to any other message.

Copy the wording, emojis, links, order and formatting exactly. Keep each line in its own paragraph. Put nothing after the CTA group.
